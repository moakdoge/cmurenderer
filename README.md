# CMU Graphics 3D-Renderer
### NOTE: This is more of a POC at the moment over a proper project. Code's a mess.


## Building Instructions:
1. `pip3 install -r requirements.txt`
2. `python3 build.py`

Your file will be in `cmu_bundle.py`; copy this file to CMU academy web to see your result. You may also just run `python3 main.py` which runs it using the local cmu_graphics.
